# Projet Test JavaScript

## Description
Ce projet est une application JavaScript minimale qui affiche "test" dans la console.

## Installation
Aucune installation n'est nécessaire. Il suffit de cloner ce dépôt pour commencer à travailler.

```bash
git clone [url-du-dépôt]
cd [nom-du-dépôt]
```

## Utilisation
Pour exécuter le script, utilisez Node.js:

```bash
node test.js
```

Cela affichera "test" dans la console.

## Structure du Projet
- `test.js` - Fichier JavaScript principal qui affiche "test" dans la console.
